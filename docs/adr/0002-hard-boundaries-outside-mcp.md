# ADR-0002：强制安全边界位于 MCP 之外

状态：已接受。

## 背景

Playwright MCP 提供 origin 过滤和文件访问护栏，Agent 提示词也能要求确认，但上游明确说明这些机制不是完整安全边界。

## 决策

生产清单必须声明企业代理、主机防火墙或隔离 VDI 作为真实网络强制层，并声明批准的模型数据路由。缺少任一项时校验器失败关闭。MCP 过滤和 Agent 规则仅作纵深防御。

## 结果

部署需要网络、安全和模型平台团队参与，不能由单个开发者只改 `.mcp.json` 就宣称生产可用。换来的是边界职责清晰，避免“配置看起来安全、实际上可绕过”。
